GUIDE IPHONE

SkillUp sur iPhone, sans App Store.

Suis les étapes ci-dessous pour installer l'application avec Sideloadly et ton propre compte Apple.

⚡ Télécharger Sideloadly  Télécharger l’IPA Voir les étapes

Le bouton IPA télécharge le fichier iPhone. Ensuite, glisse-le dans Sideloadly pour l’installer.

AVANT DE COMMENCER

Prépare ton PC Windows.

Sideloadly a besoin des versions web d’iTunes et d’iCloud sur Windows pour communiquer correctement avec ton iPhone.

✓
iTunes — version web Évite la version Microsoft Store.
✓
iCloud — version web Évite également la version Microsoft Store.
✓
iPhone reconnu par Windows Branche-le en USB et accepte « Faire confiance ».
Ouvrir les téléchargements officiels Sideloadly
INSTALLATION

Une seule configuration initiale.

Ensuite, le rafraîchissement peut être automatisé lorsque ton PC et ton iPhone communiquent.

01

Installe Sideloadly sur Windows

Télécharge Sideloadly depuis son site officiel puis termine l'installation.

02

Branche et autorise ton iPhone

Déverrouille l'iPhone, branche-le en USB et accepte « Faire confiance à cet ordinateur ».

03

Ajoute le fichier SkillUp IPA

Télécharge le fichier IPA fourni par l'administrateur du groupe, glisse-le dans Sideloadly, choisis ton iPhone puis saisis ton propre identifiant Apple.

04

Autorise l'application sur l'iPhone

Va dans Réglages → Général → VPN et gestion de l'appareil, puis fais confiance au profil développeur associé à ton compte.

05

Active le mode développeur si nécessaire

Réglages → Confidentialité et sécurité → Mode développeur, puis redémarre si l'iPhone le demande.

AUTO-REFRESH

Évite la réinstallation manuelle chaque semaine.

Laisse le Sideloadly Daemon actif sur Windows et autorise son lancement au démarrage. Lorsque le PC est allumé et que l'iPhone est détectable, Sideloadly peut renouveler la signature.

✓ Daemon actif ✓ Lancement avec Windows ✓ Même réseau Wi‑Fi ✓ PC allumé régulièrement
Important

Chaque personne doit utiliser son propre identifiant Apple. Ne partage jamais ton mot de passe Apple avec quelqu'un d'autre.
