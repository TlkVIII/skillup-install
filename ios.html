GUIDE IPHONE

SkillUp sur iPhone, sans App Store.

Suis les étapes ci-dessous pour installer l'application avec Sideloadly et ton propre compte Apple.

⚡ Télécharger Sideloadly  SkillUp fichier IPA Voir les étapes

Le bouton IPA télécharge le fichier iPhone. Ensuite, glisse-le dans Sideloadly pour l’installer.

AVANT DE COMMENCER

Choisis ton ordinateur.

La procédure change légèrement entre Windows et Mac. Sélectionne ton système pour afficher uniquement les étapes qui te concernent.

WINDOWS

Prépare Windows avant d’installer SkillUp.

Sur Windows, Sideloadly a besoin des composants Apple pour communiquer correctement avec l’iPhone.

✓
iTunes — version web Évite la version Microsoft Store.
✓
iCloud — version web Évite également la version Microsoft Store.
✓
Sideloadly pour Windows Installe ensuite Sideloadly normalement.
01

Installe iTunes et iCloud

Installe les versions web d’iTunes et d’iCloud, puis redémarre Windows si l’installation le demande.

02

Installe Sideloadly

Télécharge Sideloadly pour Windows depuis son site officiel et lance-le.

03

Télécharge SkillUp fichier IPA

Utilise le bouton « SkillUp fichier IPA » en haut de cette page, puis glisse le fichier téléchargé dans Sideloadly.

04

Branche ton iPhone

Déverrouille l’iPhone, branche-le en USB et accepte « Faire confiance à cet ordinateur » si le message apparaît.

05

Installe avec ton propre Apple ID

Sélectionne ton iPhone dans Sideloadly, saisis ton propre identifiant Apple puis lance l’installation.

06

Autorise SkillUp sur l’iPhone

Va dans Réglages → Général → VPN et gestion de l’appareil, fais confiance au profil développeur, puis active le Mode développeur si iOS te le demande.

MAC

Sur Mac, la préparation est plus simple.

Sideloadly est disponible directement sur macOS. Tu n’as pas besoin d’installer séparément iTunes et iCloud comme sur Windows.


Mac compatible Sideloadly prend en charge macOS 10.12 ou version ultérieure.
✓
Sideloadly pour macOS Télécharge simplement la version Mac.
✓
Ton propre Apple ID Un compte Apple gratuit peut être utilisé.
01

Installe Sideloadly sur ton Mac

Télécharge la version macOS de Sideloadly depuis son site officiel, puis ouvre l’application.

02

Télécharge SkillUp fichier IPA

Clique sur le bouton « SkillUp fichier IPA » en haut de la page, puis glisse le fichier IPA directement dans Sideloadly.

03

Branche ton iPhone au Mac

Déverrouille l’iPhone, connecte-le en USB et accepte « Faire confiance » si iOS ou macOS te le demande.

04

Choisis ton iPhone et ton Apple ID

Dans Sideloadly, sélectionne l’iPhone, utilise ton propre identifiant Apple puis lance l’installation de SkillUp.

05

Autorise SkillUp sur l’iPhone

Dans Réglages → Général → VPN et gestion de l’appareil, fais confiance à ton profil développeur. Active aussi le Mode développeur si l’iPhone te le demande.

AUTO-REFRESH

Évite la réinstallation manuelle chaque semaine.

Active l’option de rafraîchissement automatique dans Sideloadly et laisse son service d’auto-refresh actif sur Windows ou Mac. Lorsque l’ordinateur est allumé et que l’iPhone est détectable, Sideloadly peut renouveler la signature.

✓ Auto-refresh activé ✓ Service Sideloadly actif ✓ Même réseau Wi‑Fi ✓ Ordinateur allumé régulièrement
Important

Chaque personne doit utiliser son propre identifiant Apple. Ne partage jamais ton mot de passe Apple avec quelqu'un d'autre.
